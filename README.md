# Dialogue Ireland, redesign prototype

A design prototype that re-organises the public archive of dialogueireland.wordpress.com
(topics, groups A-Z, archive by year, search). It is **not** the official website of Dialogue Ireland.
All content belongs to Dialogue Ireland Trust and the original authors; every article links back to its original.
Not indexed by search engines. Bank and donation details are deliberately not reproduced.


## Landing concepts (added)
- `landing-wp/` WordPress.com variant: `wordpress-blocks.html` pastes into the block editor (Code editor view). Core blocks only, no custom CSS.
- `landing-elementor/` Elementor (free) variant: `elementor-template.json` imports via Templates > Import. Preview pages are approximate.
- Links to check before use: /mission-statement/, /archive/ (slugs guessed from menu names).
- Draft copy in the Help section is for review by Dialogue Ireland. Not the official site, not indexed.
